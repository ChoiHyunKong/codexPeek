# 화면 크기별 정보 설계 — 2026-09-23

## 목표

작은 창에서도 사용자가 가장 먼저 찾는 정보인 **한도 종류, 남은 비율, 리셋까지 남은 시간, 그래프**를 항상 함께 표시한다. 마우스를 올려야만 핵심 정보를 알 수 있게 만들지 않는다.

예: 주간 한도 / 69% 남음 / 리셋까지 5일 2시간 / 잔여량 그래프.
예시 수치는 설명용이며 실제 표시는 서버 응답으로 결정한다.

## 크기별 설계

| 화면 | 조건 | 표시 정보 |
| --- | --- | --- |
| 작게 | 높이 150 미만 | 한도명, 잔여 비율, 그래프, 남은 리셋 시간. 여백과 글자 크기만 줄임 |
| 기본 | 기본 270×160 및 확대 조건 미충족 | 핵심 정보 + 최근·다음 갱신 시각 |
| 확대 | 높이 260 이상, 너비 무관 | 기본 정보 + 사용한 비율, 정확한 리셋 날짜·시각, 조회 상태, 갱신 간격, 초 단위 최근·다음 갱신 시각 |
| 대시보드 | 높이 360 이상 | Codex·Gmail·Claude 좌우 카드 전환 / 세로 모두 보기, 순서 변경. 연결은 환경설정 |

크기는 Windows의 배율이 적용되는 논리 단위이다. 최소 너비는 220을 유지하고, 최소 높이는 한도 행의 실제 높이와 필요한 테두리 여백을 합산해 결정한다. 기존 130 높이 제한은 제거한다.
높이만 늘려도 상세 모드로 전환한다. 좁은 폭에서는 줄바꿈하고, 추가 카드가 넘치면 스크롤로 접근한다. [서비스 확장 기획](service-dashboard-plan.md)에 카드 표시와 연결 범위를 정리했다.

## 확대 정보의 가치

- **사용한 비율:** 잔여량과 함께 현재 소비 정도를 확인한다. 동일한 기준에서 `100 - 잔여 비율`로 계산한다.
- **정확한 리셋 시각:** 상대 시간만으로 알기 어려운 다음 작업 일정을 잡는 데 도움을 준다. PC 현지 시간으로 날짜·요일·시각을 표시한다.
- **조회 상태:** 최근 데이터인지, 조회에 실패해 이전 결과를 보고 있는지 구분한다.
- **갱신 간격과 최근·다음 갱신:** 다음 서버 조회가 언제인지 알 수 있다. 수동 새로고침 성공 시 다음 일정도 갱신한다.

## 표시 원칙

- 작은 화면에서도 한도명·비율·리셋 시간·그래프를 숨기지 않는다.
- 조회 실패나 진행 중 상태는 작은 화면에서도 표시한다. 공간이 부족하면 스크롤한다.
- 서버가 주간 한도만 제공하면 주간 한도만 표시한다. 일간 한도를 임의로 만들지 않는다.
- 리셋 날짜가 없으면 정보 없음으로 표시한다. 리셋 시각이 지나도 잔여량을 임의로 복구하지 않는다.
- 사용 이력을 저장하지 않는 현재 버전에서 소비 속도, 소진 예상 시각, 일별 증감 그래프는 만들지 않는다. 이력 수집·보관 기준을 정한 후 별도 기능으로 검토한다.

## 확인 항목

최소, 기본, 확대, 확대 경계, 좁고 긴 창, 넓고 낮은 창, 다시 줄인 창에서 핵심 항목이 유지되는지 확인한다. 두 한도는 각 기준 크기에서 스크롤 없이 표시하고, 주간 한도만 있는 계정에 일간 한도를 추가하지 않는다. 확대 화면의 조회 실패 표시도 확인한다.

## 확대 화면 가독성 보완

- 확대 모드에서 창의 너비와 높이에 따라 글자와 그래프를 함께 키운다. 340×260을 기준으로 최대 2.5배, 서비스 카드가 있는 대시보드에서는 최대 1.4배로 제한하여 추가 정보 공간을 확보한다.
- 확대 모드의 기본 글자 크기는 한도명 14, 잔여 비율 18, 리셋 카운트다운과 갱신 안내 12로 설정한다. 창이 커지면 이 값에 배율을 적용한다.
- 사용한 비율과 정확한 리셋 시각은 한 줄로 묶고, 폭이 부족하면 줄바꿈한다.
- 갱신 안내는 창 하단에 고정하지 않고 한도 정보 바로 아래에 배치한다. 한도가 하나인 경우에도 같은 규칙을 적용한다.
- 정보가 많아지면 본문을 스크롤할 수 있게 하되, 작은 화면의 기존 배치는 유지한다.
- 640×480, 900×620 및 주간 한도만 있는 확대 화면에서도 글자 배율과 본문-갱신 안내 간격을 검증한다.


## 최소 높이 보완

- 한도 1개·2개 각각 내용에 맞춰 최소 높이를 계산해 하단 빈 공간을 줄인다.
- 조회 진행 또는 실패 안내에 필요한 높이를 확보하고 정상 상태로 돌아오면 원래 최소 높이로 복원한다.
- 저장된 작은 창 높이도 유지할 수 있도록 설정 저장 범위를 조정한다. 이전 최소 크기(130 이하)로 저장된 창은 첫 조회 후 내용에 맞춘다.
